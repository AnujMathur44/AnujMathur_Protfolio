# Anuj Mathur — Personal Portfolio

A light-futuristic, responsive portfolio starter built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Download and extract this folder.
2. Open `index.html` in your browser, or use VS Code Live Server.
3. Update the content and links before publishing.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and workflow illustration design
- `script.js` — mobile navigation, project filters and back-to-top behavior
- `assets/` — add your portrait, screenshots and resume here

## Personalize before publishing
- Verify every skill and project description against your resume.
- Add project repository/demo URLs.
- Add your real email address.
- Add your resume as `assets/resume/Anuj-Mathur-Resume.pdf` and create a download link in the hero/contact area.
- Replace placeholders and remove any project that is not ready to showcase.

## GitHub Pages
1. Create a GitHub repository, for example `anuj-portfolio`.
2. Upload all files from this folder to the repository root.
3. Open repository Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

Note: The contact area currently links to LinkedIn and GitHub. A working message form needs a backend or a form service; this static starter does not pretend to send email.
